## 四、本轮修掉的缺陷（均为生产才暴露）

| 缺陷 | 现象 | 原因 | 修复 |
| --- | --- | --- | --- |
| 走查脚本命令 id 过短 | `smoke 通关失败：输入不符合要求。` | `commandSchema.id` 要求 ≥8 字符，脚本生成 `smoke-0` 只有 7 个 | 统一改成 `smoke-cmd-` / `ui-cmd-` / `bulk-cmd-` 前缀 |
| 换前端产物后整站白屏 | 生产 `/assets/index-*.js` 返回 404，首屏等待超时 | `@fastify/static` 用 `wildcard:false`，启动时**记录当时的文件清单**；替换哈希文件后路由表里没有新文件 | 部署流程固定为「替换 dist/web → `pm2 restart iot-city`」 |
| 预览服务把板子接口写成空桩 | 终端页本地走查显示「章节 0 个，关卡 0 关」 | `preview-server.ts` 里 `/api/board/*` 直接返回 `[]` | 挂上真实内容包 + 真实 `runner`（`createRun/submitEvidence/...`），预览与生产判定逻辑同一套 |
| 终端页断言时序不稳 | 偶发「考察项面板为空」 | 用 `body.innerText` 匹配，命中出现在首次渲染的瞬间 | 改为等选择器 `Boolean(document.querySelector('.terminal-probe'))` |

更早一轮生产独有的两个缺陷（已修，留档）：MySQL 8 `ER_FIELD_IN_ORDER_NOT_SELECT`（`/api/levels` 500）、数据加载慢导致门禁断言早于章节 Tab 渲染。

## 八、视觉重做与题库补齐（v4 新增）

### 8.1 主题：深色 → 白蓝 / 白绿

| 项 | 做法 | 产物 |
| --- | --- | --- |
| 底色 | `#0b1117` 深青 → `#f4f8f7` 纸白 + 青蓝雾 | `apps/web/src/styles/01-foundation.css` |
| 卡片 | 半透明深色块 → 纯白 + 1px 细边 + 三级轻投影 | `apps/web/src/styles/07-light-polish.css` |
| 强调色 | 薄荷绿高亮 → 主操作用 `#0f9b7d`，信息用 `#2563eb`，提醒用 `#b45309` | 同上 |
| 转换方式 | 先按明度/饱和度做一次机械反色（`scripts/lightify.mjs`），再**人工逐块修正**：面板、英雄区、简报浮层、章节插画、表格、表单 | 10 个样式文件 |
| 保留例外 | 板载屏幕预览（`.board-screen`）刻意保持深色，模拟真实 TFT | `styles/terminal.css` |

反色脚本只做“底/字/强调”三档映射，灰扑扑的半透明面板（`.continue-panel` / `.topbar` / `.briefing-panel` 等 9 处）是逐条手改的，不是脚本产物。

### 8.2 3D 现场：程序化色块 → 真实材质 + 手写布景

- **材质来源**：ambientCG 的 CC0 素材（Concrete034 / PavingStones070 / Asphalt012 / Metal046A / Metal032 / Wood066 / Tiles074 / Grass004），裁到 512px 转 JPG，全站 **463KB / 23 张**，放 `apps/web/public/tex/`。
- **场景布景**：`apps/web/src/scene/kits.tsx` 手写十个场景——城市（石材广场 + 沥青路 + 玻璃塔）、实验室（瓷砖 + 工作台 + 试剂架）、大棚（种植槽 + 玻璃幕墙 + 管线）、家居（木地板 + 沙发 + 窗）、车间（混凝土 + 机床 + 护栏 + 托盘）、机房（防静电地板 + 机柜 + 走线架）、路口（路面标线 + 信号灯 + 路灯）、电力（变压器 + 杆塔 + 围栏）、网络（机柜 + 配线架 + 操作台）、危机（残墙 + 应急灯）。
- **设备外形**：10 类设备各自有实体造型（传感器/执行器/无线/控制器/网关/云端/供电/识别/终端/路由），金属度与粗糙度分材质，标签改为 sprite 永远正对镜头。
- **相机**：弃用 `OrbitControls`（它与 `lookAt` 叠加会产生滚转，把地平线拧歪），改为自写球坐标轨道，位置永远由 `target + 球坐标` 反推。
- **踩过的坑**（都写进代码注释了）：阴影相机范围小于地坪会形成大片假阴影；克隆贴图时图片未解码会让克隆体永远没有图（改为按“材质+密度档”共享实例，不克隆）。
