# 教师使用手册

教师账号由管理员创建或将已注册的学生账号调整为教师。公开注册只会创建学生账号；教师登录后使用 HttpOnly Cookie 会话，班级、名册和内容操作由服务端按教师身份及所属关系检查。

## 班级与学生

1. 在教学管理页创建班级，保存页面显示的邀请码并发给学生。
2. 学生以学生账号登录后输入邀请码加入班级。学生可查看自己的班级及班级作业；不能读取名册、报告或导出文件。
3. 教师可查看自己班级的成员、完成数和累计分数，移除班级成员，并把班级成员分成小组。分组成员必须属于当前班级。
4. 在班级作业页选择已发布且对该班可见的关卡，填写标题、模式和可选截止时间。
5. 查看班级报告中的成员、作业、成绩、知识点统计和分组；可导出 CSV。导出会添加 UTF-8 BOM，并对以公式符号开头的单元格做转义。

教师不能读取其他教师班级的名单、报告或导出。学生的会话事件只能按系统提供的本人或授权教师访问边界读取。

## 编辑、预览和发布内容

1. 在内容管理中新建草稿。编辑器需要符合共享关卡 Schema：至少一个设备、两个任务、有效设备连接/规则、教学解析、参考链接和至少三个解法操作。
2. 保存现有草稿时，提交其当前 `version`；服务端把新内容写为不可变的新版本。版本冲突时重新载入后再编辑。
3. 使用预览创建 `preview` 会话。预览结果不进入正式排行榜。
4. 发布时选择自己负责的班级。教师无权全局发布，且不能编辑系统种子关卡。
5. 学生进入已发布内容并开始会话时，服务端记录内容版本。后续修改和发布新版本不会替换既有会话所绑定的版本。
6. 回滚会把历史定义复制为一个新的草稿版本；不会覆盖旧版本。停用内容会保留历史版本和既有记录。

内容列表的可见范围由作者、发布范围、班级成员关系和管理员权限决定。官方种子关卡可由教师查看并作为新草稿基础，但不能由教师直接覆盖。

## 题库与关卡题目

1. 打开“题库管理”，可创建题库草稿，或从 20 道专业模板创建自己的可编辑题目。模板覆盖 IPv4 子网、DHCP、DNS、MQTT、TLS、VLAN、PoE、I²C/SPI、采样、RS-485、工业仪表、控制与数据治理等知识。
2. 为单选/多选题维护稳定且不重复的选项 ID；正确答案必须对应现有选项。数值题可设置容差；文本题填写标准文本。每题需要解释、知识点和分值。
3. 教师可以把自己题目发布到自己负责的班级；管理员可发布到班级或全局。修改题目会将该题退回草稿。已复制到关卡里的题目是独立副本，之后题库更新不会改写该副本。
4. 在内容工坊编辑关卡时，从题库选择已发布题目或自己的草稿，将题目复制进 `level.questions`；可在关卡内继续编辑或删除副本。
5. 任务条件可选择已嵌入题目并添加答题谓词：`source=flag`、`target=answered:<题目ID>`、`op=exists`。答对后由游戏引擎维护该标记；任务同时应要求真实设备配置、连接或仿真等工程目标，题库不能代替工程互动。

学生账号不能调用题库管理接口取得正确答案。学生从公开关卡读取题目时，`answer` 和 `explanation` 字段会从题目视图移除；正确答案不应经普通题库或关卡详情暴露。

## 真实实现限制

- 教师发布只支持当前负责班级；全局发布需要管理员。
- 题库题目按单题更新和停用，不维护题目版本历史；关卡内已复制的定义会独立保留。
- API 契约没有教师创建/提升账号的公开入口，账号角色由管理员维护。
- 本手册描述当前 API 的班级、内容、作业、报告、导出与版本行为，不代表这些流程已连接实际数据库或完成真实浏览器联调。请以部署环境中的实际权限和页面为准。
