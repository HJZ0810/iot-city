# 管理员使用手册

管理员账号通过独立账号登录。浏览器使用 HttpOnly Cookie 会话；不要复制、导出或共享会话 Cookie。注册接口只能创建学生账号，管理员在用户管理中调整角色。

## 用户与访问

- 用户列表可查看账号、昵称、角色和禁用状态。管理员可以修改角色、昵称或禁用账号。
- 角色变化或禁用操作会撤销目标账号所有旧会话；该用户需要重新登录。
- 密码重置会立即撤销目标账号的所有会话。通过可信渠道将新密码交给用户，并要求其后续自行更换。
- 系统会阻止降级或禁用最后一名有效管理员。维护管理员账号时，先确认至少还有一名可用管理员。
- 管理员可查看近期审计记录，检查账号、内容和设置变更。

## 内容、赛季与设置

- 管理员可查看全部内容并处理内容发布范围；教师只能发布到所属班级。
- 赛季创建保留历史记录。赛季切换及历史榜单展示按实际运营规则操作。
- 设置项包括每日挑战刷新小时、事件保留天数、当前赛季 ID 和房间人数上限。接口会检查字段范围；修改前确认当前比赛和运营安排。
- 资源登记仅接受受控 `/assets/...` 相对 URL 元数据，并拒绝路径回退片段；它不会上传文件，也不会读取任意服务器路径。
- 当前 API 上下文未提供受控备份/恢复操作，管理后台不应以本地按钮或手工数据库命令替代正式备份流程。

## 题库管理

管理员可浏览自己创建的题目和已发布题库，编辑或复制授权范围内的题目，发布到获授权的班级或全局，或停用题目。全局发布只允许管理员。题目答案按题型校验：单选答案必须指向一个选项，多选答案必须是选项 ID 的非空子集，数值题答案必须为数字，文本题答案必须为非空文本；选项 ID 不能重复。

题库详情接口只对教师和管理员开放，并按作者、发布范围和班级关系检查权限。学生没有读取题库详情答案的权限；学生端只从关卡公开视图取得问题，`answer` 与 `explanation` 会被 `publicLevel` 剔除。修改题库不会更新已复制到 `level.questions` 的题目副本。题目模板是工程知识练习素材，不是学生成绩或成绩数据。

## 状态查看与验收

管理员可查看运行概览、健康状态、用户/班级/关卡/会话/成绩计数及活跃房间数量。系统健康接口的数据库状态只能说明当次数据库探测结果，不代表备份、恢复或长期稳定性已验证。

API 集成验收脚本会创建唯一前缀的临时用户和业务记录，不自动删除数据；请优先使用隔离数据库与临时管理员凭据。详细命令及验证边界见 [API 验收说明](API_ACCEPTANCE.md)。

## 验证状态与限制

本手册依据当前核心 API 与管理路由实现整理。此工单没有连接实际 API/数据库，也未访问服务器；不能据此声称管理员流程已在目标环境联调通过。部署、账号初始化、备份、恢复和浏览器验收需分别留存实际环境证据。
